# Inventory Tracker

A small Python inventory program for SEN 401, Lab 3 (Configuration Status Accounting).
It holds a list of shop items with quantity and price, and works out the total stock value.

## Files

- `inventory.py`: the list of items (item_name, quantity, price)
- `app.py`: reads the inventory and prints the total stock value
- `utils/helpers.py`: helper functions such as `highest_stock_item()` and `lowest_stock_item()`
- `requirements.txt`: dependencies

## How to run

```bash
python app.py
```
